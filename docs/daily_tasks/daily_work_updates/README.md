## Status Definitions
- **Completed:** Assigned work has been completed and evidence is available.
- **In Progress:** Work has started but is not complete.
- **Pending:** Work has not started.
- **Blocked:** Work cannot continue due to a dependency or issue.
- **Partially Completed:** Only some assigned tasks have been completed.

## Reporting Guidelines
1. Every member must share their daily work update with the Project Coordinator.
2. Record actual work, not planned work.
3. Include relevant filenames, commit hashes, Pull Request links or screenshots where applicable.
4. If a task is incomplete, explain the reason.
5. The Project Coordinator updates the daily work record.
6. Create a separate Markdown file for each working day using `YYYY-MM-DD.md`.
7. Preserve previous records for project review and progress tracking.
